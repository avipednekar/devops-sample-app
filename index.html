About This Project

This is a sample web application created as part of a DevOps laboratory experiment. It demonstrates the development of a responsive webpage using HTML, CSS, and JavaScript.

Git is used to track source-code changes, while GitHub provides remote repository hosting and collaboration features. The application can also be published using GitHub Pages.

Technologies Used

Essential tools used to build, manage, and publish this sample application.

🌐

HTML

Structures the webpage using headings, paragraphs, navigation, sections, buttons, and other elements.

🎨

CSS

Adds colors, spacing, layouts, responsive design, transitions, and a consistent visual appearance.

⚡

JavaScript

Adds interactivity, responds to user actions, and displays application status messages.

🔧

Git

Tracks source-code changes, records commits, and helps developers manage different versions of a project.

🐙

GitHub

Hosts the remote Git repository and supports code sharing, collaboration, and project history.

🚀

GitHub Pages

Optionally publishes the static HTML, CSS, and JavaScript application as a live website.

Our DevOps Workflow

The basic steps followed in this laboratory experiment.

01. Develop

Create the webpage using HTML, CSS, and JavaScript.

02. Test

Open the application in a browser and verify its functionality.

03. Version Control

Initialize Git, stage the files, and commit the changes.

04. Upload to GitHub

Connect the local repository to GitHub and push the main branch.

05. Publish (Optional)

Configure GitHub Pages to make the static application available online.
